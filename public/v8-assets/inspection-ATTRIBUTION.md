# WD-01 巡检概念参考

模型取自用户提供的 EmbodiX 官网交付源代码。底层四足网格是 Unitree Robotics / Google DeepMind MuJoCo Menagerie 的 BSD-3-Clause 许可衍生版本，固定提交 71f066ad0be9cd271f7ed58c030243ef157af9f4。许可全文见 inspection-LICENSE.txt；原修改记录见 inspection-source-DERIVATION.json。

巡检相机、热像模块、近距感知、计算、电气及安装件是该站点提供的概念加装几何，不是制造商原装结构或已验证设备。未将这些组件改标为 CC0。当前导出保留默认站立配置，排除隐藏的可选雷达、支架和假设载荷。

已逐项核验 39 个来源文件；导出 183 个可见 mesh、410641 个三角面实例、55 个实际可见目录组件。原始构造器包含 186 个 mesh 和 57 个目录组件，差异为明确隐藏的配置。保留当前位置、朝向、缩放、材料分组和网格精度，未减面；不携带网站运动/物理控制器。

这是一份细节丰富的可视化/结构参考，不是原生 CAD、完整制造 BOM、安装认证或工程验证。拆解只对文件中的实际组件进行可逆平移，不补造来源没有证实的内部硬件。
