# 当前界面与交互说明

适用工程：`frontend-v8`。更新：2026-11-16。本文描述当前可运行界面，不是对后端能力的承诺。

## 1. 产品边界与入口

EmboMiX 是工作空间，Embodex 负责从需求到设计交付。Simcore、Deployx 保留模块展示、组合和项目归属；当前不提供真实仿真或部署。

预览入口 `/v8`，未登录时进入 `/v8/login`。演示数据保存在当前浏览器，生产入口 `/design` 使用平台身份与项目读取，V8 未接通的写入操作保持阻断。原平台路由为兼容既有功能保留，不与演示数据混用。

## 2. 登录、注册与找回密码

入口：`/v8/login`；组件：`PreviewSignIn.tsx`。

- 密码登录：示例账户 `123`，密码 `123`。
- 短信登录、注册、找回密码在同一登录界面切换；本地示例验证码为 `123456`，不发送真实短信。
- 注册可填写手机号及补充信息，协议弹窗支持关闭；本地注册密码以加盐摘要保存。此机制不等同于生产认证。
- 左侧是需求输入、机器人设计、场景演示和部署演示的实时三维动画；不创建业务任务。
- 登录成功进入 EmboMiX 工作空间；已有演示登录态再次打开页面时提供继续入口。

真实认证、验证码和账号恢复的后端工作见 [后端说明](BACKEND_INTEGRATION.md)。

## 3. EmboMiX 工作空间

入口：`/v8`、`/v8/workspace`；组件：`PreviewExperience.tsx`、`WorkspaceProjectOverview.tsx`。

| 区域       | 当前行为                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------- |
| 项目列表   | 搜索项目，按所选模块组合筛选；项目圆点用于视觉区分。点击项目先在右侧显示概览，不直接进入设计阶段。 |
| 项目概览   | 展示需求、已完成内容、当前进度和继续入口；选择项目后不在下方重复显示模块卡片与工作流。             |
| 模块卡片   | 单击选中，再次单击取消；组合与拖动顺序是工作空间配置。卡片拖动时跟随指针。                         |
| 模块筛选   | 按完全相同的模块集合筛选；进入 Embodex 后项目列表仍受所属组合约束。                                |
| 进入与返回 | Embodex 可进入；返回工作空间恢复组合、搜索和项目选择。Simcore、Deployx 不宣称已执行真实任务。      |

组合模块不等于启动跨模块后台流水线。模块顺序与项目归属存于浏览器，未来需后端持久化。

## 4. Embodex 设计首页

入口：`/v8/embodex`；主要组件：`Studio.tsx`。

输入设计目标、附加需求文件，或从已有项目继续。浏览模板本身不创建项目；明确使用模型或开始设计时才写入项目。项目恢复最近合法位置，重新进入不会自动打开设计历程。

当前可读取本地 TXT / Markdown。PDF、DOCX 等格式的上传解析需要后端文件与解析服务，不能把选择文件视为已完成服务端上传。

## 5. 明确需求

入口：`/v8/projects/:id/requirements`；结构化表单：`RequirementsBrief.tsx`。

设计目标之外，按以下已有分组编辑：

| 分组       | 字段                                           |
| ---------- | ---------------------------------------------- |
| 任务与场景 | 任务与对象、作业场景、任务载荷                 |
| 运行与安全 | 空间与工作范围、作业性能、环境边界、安全与协作 |
| 对接与验收 | 系统对接、验收标准                             |
| 补充说明   | 其他用途说明、其他约束说明                     |

保存形成需求版本并进入设计探索。缺失信息保持待确认，不把示例性能或预算当成项目事实。实质修改使后续设计需要重新确认；旧成果留在设计历程。离开未保存的表单会提示保存、放弃或继续编辑。

## 6. 设计探索

入口：`/v8/projects/:id/start`。

两条路线分别是“模板库”和“专业定制”。用户可返回明确需求，也可在有模板的情况下选择专业定制。

### 模板网格

`/library` 属于设计探索。卡片显示机器人概览、模型来源与可调范围；点击“查看模型”后才进入模型概览。当前活动模板为 Go2 精细结构参考、Q4 精细巡检构型、C2 精细移动平台。旧示意模型只用于历史兼容。

### 专业定制候选

`/concepts` 列表仍属于设计探索。可生成、比较、追加方向，卡片展开“设计取舍”；点击具体方向后才进入模型概览。部分成功、空结果与失败分别展示，已有方向不因重试而丢失。可返回设计探索。

预览的方向来自确定性样例，并非真实 Agent 自动生成。生产需要返回真实分支和素材。

## 7. 模型概览

| 路线     | 入口                                       | 主要操作                                                                           |
| -------- | ------------------------------------------ | ---------------------------------------------------------------------------------- |
| 模板     | `/library?template=:templateId`            | 查看与拆解、选择部件、调整受支持参数、保存适配、返回模板网格、携带模型进入专业定制 |
| 专业定制 | `/concepts/:branchId?revision=:revisionId` | 查看具体版本、切换方向、提交修改、保存参数为新版本、确认该版本、返回候选网格       |

左侧为模型，右侧为现有部件与参数面板。支持旋转、缩放、整机还原、连续拆解、部件定位与感知结构查看。网格数量、三角面和原始节点放在已有部件详情中。仅图片的概念不提供伪三维控件。

参数只来自已声明范围：当前 Q4/C2 开放完整相机组的高度偏移；原始 Go2 不提供没有依据的结构调整。保存配置会导出对应 GLB；临时旋转、拆解不会改变模型文件。

专业定制每次修改形成独立修订。确认锁定该修订的需求、描述、模型与参数；未保存参数不能直接确认。完整版本列表在“设计历程”。

## 8. 工程模型

入口：`/cad`，可带 `?run=:runId` 查看指定记录。

- 模板路线展示已经保存的配置模型，可返回对应模板与参数；直接复用时不增加 CAD 任务。
- 专业定制显示所确认版本的工程任务、状态、模型与文件。创建任务前有确认弹窗，预览明确标为样例工程任务。
- 等待、运行、失败、未知受理和文件准备状态分别处理；失败可重试，不以旧成功文件冒充新结果。
- “查看交付成果”进入方案交付，不自动打开设计历程。返回概念时保留确切来源版本。
- 当前没有真实 SolidWorks 执行或工程验证。配置 GLB 是真实可打开的几何文件，但不是制造 CAD。

## 9. 方案交付

入口：`/delivery`。

只有两张成果卡：

1. **设计方案**：当前最终 HTML 的在线概览与下载。
2. **三维模型**：独立交互查看与下载对应模型文件。

模板完成模型选择、适配保存和文件准备，或专业定制完成确切版本确认、对应工程任务与文件准备后，才生成最终 HTML。同一来源幂等生成；未完成时说明缺失步骤并使用现有继续入口。任务失败、文件校验中、无权限或来源不一致时不提前提供成果。

新的实质修改不会用旧成果顶替当前结果。旧 HTML、Markdown 记录、模型和工程结果通过设计历程访问。

“进入 Simcore”保留设计交接入口，当前进入的是“暂未开放”状态与来源信息，可返回方案交付，不启动仿真。

## 10. HTML 完整方案

入口：“查看完整方案”弹出的独立阅读器；实现：`OfficialDesignReport.tsx`、`lib/v8/official-report.ts`。

沿用官网七章布局与组件，只替换当前方案内容：

| 章节       | 内容与来源                                                             |
| ---------- | ---------------------------------------------------------------------- |
| 需求与方案 | 该成果绑定的需求版本、目标、模型及确认状态                             |
| 交互式方案 | 与成果匹配的模型文件、参数快照、整机/拆解/部件操作                     |
| 整体方案   | 对应模型设计、配置、任务载荷和系统对接；不沿用其他官网案例的能力说明   |
| 场景任务   | 从冻结的任务、场景、边界、安全和验收字段组织步骤；缺少的字段标为待确认 |
| 投资预算   | 由用户填写的测算假设，未提供金额不填示例价格                           |
| 企业效益   | 基于当前输入计算，缺少关键假设时显示“—”，不视为已验证收益              |
| 交付流程   | 该路线的需求、设计、模型和成果关系，保留模型来源与许可                 |

顶部保留打印/另存 PDF、下载 HTML 和关闭。已移除页尾“保存当前方案”区块及 JSON / 重复导出按钮。

报告内模型参数调整和预算输入用于当次查看，不改写冻结方案。修改正式设计需回到相应阶段保存新版本。下载 HTML 为离线阅读版，内嵌图片、保留章节锚点及当前测算值；离线版不包含完整三维运行时。在线三维仍可交互，GLB 单独下载。

## 11. 设计历程、助手和公共弹窗

| 界面       | 当前作用                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------- |
| 设计历程   | 分方向查看概念版本、需求记录、工程记录、旧成果和设计事件；回看不生成任务、不覆盖历史                      |
| AI 助手    | 当前为受控的页面/模型命令解释器，如拆解、还原、聚焦、支持的参数调整和页面导航；任意拓扑设计不伪装为已完成 |
| 比较方向   | 查看不同候选的差异和限制，选择后仍引用原分支                                                              |
| 确认设计   | 明确确认版本，冻结描述与参数，再进入样例工程任务                                                          |
| 未保存提示 | 保存后继续、放弃修改或继续编辑，避免误丢需求/参数/修改要求                                                |
| 文件预览   | 模型与文本历史使用对应查看器；缺失、无权限或未就绪时阻止读取                                              |

关闭控件、Escape、焦点恢复和手机按钮命中已纳入回归。源 ID 保留在数据关系中，不作为普通用户的说明文字展示。

## 12. 维护位置

界面主流程在 `components/v8/Studio.tsx`，数据约束在 `lib/v8/state.ts`、`delivery-packages.ts` 和 `repository.ts`；不要把来源校验移入按钮文字或展示组件。后续接入后端应替换 adapter 的能力实现，保留现有路线、版本和文件语义。
