# Embodex V8

当前活动前端工程，基于 Next.js、React、TypeScript 和 Three.js。包含 EmboMiX 工作空间，以及 Embodex 的明确需求、设计探索、模型概览、工程模型、方案交付两条完整前端路线。

**当前可体验的是本地演示。真实 Agent、SolidWorks、V8 业务持久化、短信、仿真和部署服务尚未接通。** 不要将界面中的样例任务视为真实 CAD 执行。

## 快速启动

需要 **Node.js 22.13+** 和 **pnpm 11.25.0**。本次独立解压验证使用 Node.js 24.22.1。尚未安装 pnpm 时，可先执行 `npm install --global pnpm@11.25.0`。

完整解压 ZIP，进入包含 `package.json` 的 `frontend-v8` 文件夹，执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

默认访问 <http://127.0.0.1:3108/v8>。账户 **123**，密码 **123**。端口被占用时启动器会尝试后续端口，以终端打印的实际地址为准。Windows 安装依赖后也可运行 `启动预览.ps1`。

首次安装依赖需要联网。启动和下述演示不需要原始 `frontend`、官网文件夹、其他模型目录、`.env.local`、后台服务或 SolidWorks；运行模型、图片、照明和报告样式都已随包提供。请保持启动终端运行，用支持 WebGL 的现代浏览器访问，不要直接双击源码 HTML 或用 `pnpm start` 代替开发预览。

登录后进入 EmboMiX，选择 Embodex，或在左侧选择项目查看概览后继续。推荐先打开“仓储巡检 · 完整流程示例”体验七章 HTML 和对应模型；也可新建项目完整走两条路线。

快速验收：选择该完整示例 → 继续设计 → 方案交付。分别尝试“查看完整方案”及顶部“下载 HTML”，再尝试“三维模型”的“在线查看”和“下载”。在线模型可拖动旋转、拆解并选择部件；下载的 HTML 可断网阅读，下载的 GLB 不需要原工程中的纹理文件。

短信/注册/找回密码是同一登录页内的本地演示，示例验证码 `123456`，不发送短信。用户项目、版本、对话和工作空间选择保存在当前浏览器；更换浏览器不会自动同步。

## 当前关键行为

- 模板路线：选模型 → 查看/拆解/调整支持参数 → 保存适配 → 文件就绪 → 最终 HTML 与独立模型。直接复用不增加 CAD 流程。
- 专业定制：需求 → 多方向 → 选具体版本 → 修改形成新版本 → 确认 → 样例工程任务 → 对应文件就绪 → 最终 HTML。
- HTML 只针对满足条件的当前来源生成一次；不为每个阶段生成，失败、文件校验中或来源不一致时不能提前交付。
- 当前成果与历史分开；完整版本、需求和工程记录在“设计历程”，查看不创建任务。新修改不覆盖旧成果，也不用旧成果顶替当前设计。
- 方案七章沿用官网布局，内容读取冻结的需求、描述、模型和参数。顶部提供打印/另存 PDF、下载 HTML、关闭；已移除页尾重复保存区与 JSON 导出。
- 在线模型可旋转、拆解和选择部件；下载 HTML 用于离线阅读，GLB 单独下载。预算和效益为当次测算，未填写的数据不套用官网示例数值。
- Simcore、Deployx 当前不开放业务功能；工作空间的模块组合不是后台任务流水线。

## 工程结构

```text
app/v8/                   本地演示入口与错误页
app/design/               平台模式 V8 入口
app/api/v8-preview/       开发专用配置 GLB 导出
components/v8/            工作空间、登录、阶段页面、查看器、助手、方案阅读器
lib/v8/                   类型、repository、状态约束、来源检查与内容适配
lib/api/                  原平台客户端与生成 SDK
lib/auth-*、lib/hub/…     原平台认证及既有集成
public/v8-assets/         当前模型、封面、动画资源、许可和来源记录
scripts/                  本地启动、隔离构建、素材维护工具
test/                     领域测试与浏览器回归源码
docs/                     当前交接文档
```

其他 `app/`、`components/` 和 `lib/` 目录包含原平台功能和必要依赖，保留兼容。没有修改原始的独立 `../frontend`。使用本目录作为活动工程即可，不需双向同步。

## 开发与验证

```sh
pnpm typecheck
pnpm lint
pnpm test:v8
pnpm test
pnpm build
```

预览运行时，可在另一终端执行：

```sh
node test/v8-e2e.mjs
node test/v8-report-content-qa.mjs
node test/v8-report-toolbar-qa.mjs
node test/v8-route-walkthrough-qa.mjs
```

浏览器专项默认使用本机 Edge；环境需要可用的 Playwright 浏览器，按对应脚本的 channel 配置调整。测试使用独立浏览器上下文，不读取或重置用户的浏览器项目。自动生成的截图、下载和日志位于 `test-results/`，不属于运行内容或交付包。

需要原始官网/模型目录的素材转换和参考来源对照脚本是维护工具，不是启动前置条件。当前可运行产物已在包内，详见素材说明。

`pnpm test:v8` 只使用包内文件。原始 OBJ/MJCF/官网源码对照单独运行 `pnpm test:v8:source`，维护者需通过 `V8_GO2_SOURCE_DIR` 和 `V8_MOBILE_SOURCE_FILE` 指定对应原始来源；普通使用无需运行。`pnpm test` 是保留的原平台回归，既有失败及外部脚本要求见验收记录。

浏览器回归若使用了其他端口，可设置 `V8_PREVIEW_URL`，例如 PowerShell 中先执行 `$env:V8_PREVIEW_URL='http://127.0.0.1:3109/v8'`。`test/v8-e2e.mjs`、`test/v8-report-toolbar-qa.mjs` 和 `test/v8-report-stream-interaction-qa.mjs` 支持此设置；E2E 会拒绝来自其他站点或预览端口的素材请求。

## 两种模式

| 入口      | 数据与能力                                                                                               |
| --------- | -------------------------------------------------------------------------------------------------------- |
| `/v8`     | 非 production 且 `ENABLE_V8_PREVIEW=1` 才启用；`pnpm dev` 自动设置。本地账号、项目、样例任务与模型文件。 |
| `/design` | 平台 Cookie 身份与项目读取。未确认的 V8 写入能力主动阻断，不静默回退演示。                               |

`.env.example` 只含公开配置示例。真实平台可设置服务端 `PLATFORM_BACKEND_ORIGIN`，浏览器保持同源 `/api/v1`；不要把服务密钥放到客户端环境变量或代码中。

`pnpm build` 使用 `.next-production`，不覆盖正在运行的开发缓存。`pnpm start` 默认启动本机 3109 的平台模式；生产下 `/v8`、`/v8-assets` 和 `/api/v8-preview` 返回 404，这是预览隔离规则，不是构建失败。后端未接入前，请用 `pnpm dev` 进行本地产品体验。

## 交付包与维护原则

ZIP 包含源码、锁文件、启动配置、必要素材、许可证、测试源码和当前文档；不包含 `node_modules`、构建缓存、生成原稿、历史截图/下载、用户浏览器数据或密钥。首次打开需安装依赖。

继续开发时复用当前组件与 repository，保持 Liquid Glass 风格。不要删除用户项目/设计历程，不要把本地预览包装成真实工程服务；后端接入按文档中的来源、任务和文件约束完成。
